# Shah Mobiles & Accessories

A modern storefront website for Shah Mobiles & Accessories built with HTML, CSS, and JavaScript.

## Features
- Responsive landing page
- Product gallery and category browsing
- Cart, wishlist, and checkout flow
- Dark mode and language toggle UI
- Admin page for product management

## Project Structure
- `index.html` — homepage
- `css/` — stylesheets
- `js/` — JavaScript functionality
- `assets/` — images and icons
- `admin/` — admin-related pages

## How to Run
1. Open the project folder in your browser.
2. Start with `index.html`.

You can also serve the folder with a simple local server if you want to avoid file path issues.

## Technologies Used
- HTML5
- CSS3
- JavaScript
